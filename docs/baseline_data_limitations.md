# Baseline Data Limitations - Open-Source UUV Energy Inputs

Simulating UUV energy demands requires accurate inputs regarding battery capacity, endurance, speed range, and recharge behavior. However, detailed operational parameters for specialized unmanned systems are often unavailable in open literature, restricted to vendor discussions, or embedded in reports that may carry distribution or export-control limitations. For this reason, this project avoids reliance on compiled restricted tables when the same baseline can be reconstructed from primary public manufacturer data.

To address this limitation without compromising the simulation's validity, this research uses published specifications from well-documented commercial and standard-issue Small and Medium UUV families. The baseline catalog is limited to open-source data from REMUS/HII, Bluefin/General Dynamics, and Iver/L3Harris platforms. These sources provide public values for battery capacity, endurance, nominal operating speed, maximum speed, and, in some cases, recharge time.

The resulting model is therefore not a classified or operational performance model. It is an academic planning-support model that reflects the approximate energy limits of real hardware families using public technical specifications. The current baseline spans battery capacities from approximately 0.78 kWh to 7.5 kWh and endurance values from approximately 6 hours to 30 hours, depending on vehicle configuration. These values are sufficient for comparing mission-level energy demand, battery-set requirements, recharge burden, and stockpile planning sensitivity across representative S/M UUV systems.

Where manufacturers do not publish a parameter, the model uses a clearly marked engineering planning assumption rather than an inferred classified value. In the current baseline, the model applies an 88 percent usable battery fraction to account for reserve planning and battery-health margin. When recharge time is not published, the model uses a provisional recharge estimate of four hours per kWh of battery capacity. These assumptions should be replaced with platform-specific data when approved sources become available.

This limitation should be stated explicitly in the paper: the model is designed to be transparent, repeatable, and source-traceable. It should not be interpreted as a performance guarantee for any specific vehicle configuration, payload, or operational environment.
