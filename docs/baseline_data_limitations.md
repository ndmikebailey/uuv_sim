# Baseline Data Limitations - Open-Source UUV Energy Inputs

Simulating UUV energy demands requires accurate inputs regarding battery capacity, endurance, speed range, and recharge behavior. However, detailed operational parameters for specialized unmanned systems are often unavailable in open literature, restricted to vendor discussions, or embedded in reports that may carry distribution or export-control limitations. For this reason, this project avoids reliance on compiled restricted tables when the same baseline can be reconstructed from primary public manufacturer data.

To address this limitation without compromising the simulation's validity, this research uses published specifications from well-documented commercial and standard-issue UUV families. The baseline catalog includes open-source data from REMUS/HII, Bluefin/General Dynamics, and Iver/L3Harris platforms, plus validated public-facing system mappings recorded in `UUV Project file Notes.md`. These sources provide public values for battery capacity, endurance, nominal operating speed, maximum speed, and, in some cases, recharge time.

The resulting model is therefore not a classified or operational performance model. It is an academic planning-support model that reflects the approximate energy limits of real hardware families using public technical specifications. The current baseline spans battery capacities from approximately 0.78 kWh to 15.0 kWh and endurance values from approximately 1.5 hours to 110 hours, depending on vehicle configuration. These values are sufficient for comparing mission-level energy demand, battery-set requirements, recharge burden, and simplified sustainment energy-flow sensitivity across representative UUV systems.

Where manufacturers do not publish a parameter, the model uses a clearly marked engineering planning assumption rather than an inferred restricted value. In the current baseline, practical usable battery fraction is sampled by Low/Medium/High condition and remains separate from operator reserve margin and temperature derating. When recharge time is not published, the model uses a provisional recharge estimate of four hours per kWh of battery capacity. Salinity follows the active v3.5 hierarchy of NOAA CO-OPS station data when available, NOAA WOA23 climatology when available, and standard seawater assumption otherwise. WOA23 is climatological/historical, not live tactical METOC. Copernicus was evaluated during development and removed from the active v3.5 salinity chain. HYCOM/GOFS, SMAP, and Argo remain future enhancement or V&V sources only. Salinity and density inputs are planning modifiers only and are not tactical oceanographic authority. Payload Delivery payload-mass burden does not rely on public dry-weight data; payload mass is treated as a bounded trim/integration planning penalty scaled against vehicle energy class because payload weight alone is not a direct hydrodynamic drag variable. Payload-specific drag modeling is future work if area, Cd, mounting, buoyancy, and trim data become available. These assumptions should be replaced with platform-specific data when approved sources become available.

The fuel-equivalent sustainment lens uses a conservative 10.0 kWh/gal JP-8/diesel tactical-generator planning factor derived as a public planning simplification. It is not a generator-specific certified fuel curve and should be validated against known generator curves if a specific generator is selected later.

This limitation should be stated explicitly in the paper: the model is designed to be transparent, repeatable, and source-traceable. It should not be interpreted as a performance guarantee for any specific vehicle configuration, payload, or operational environment.
